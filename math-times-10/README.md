# 10×10 Multiplication Mission

A Three.js + GSAP learning game for practicing multiplication facts up to 10×10.

## Branch
`web/multiplication-course-10`

## Path
`math-times-10/index.html`

## 10-step course
1. Warm-up check
2. Meet the 10×10 map
3. Count by 2s
4. Use 5s and 10s
5. Same × same diagonal facts
6. Mirror facts
7. Easy-friend memory tricks
8. Rectangle builder
9. Speed practice
10. Final check with before/after score comparison

## Notes
- The page uses Three.js for a floating 10×10 cube wall in the background.
- The page uses GSAP for transitions, highlights, motion, and feedback.
- This branch is separate from main, so it is not live on GitHub Pages until merged or Pages is configured to use this branch.
