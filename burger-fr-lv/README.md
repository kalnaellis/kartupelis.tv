# French ⇄ Latvian Burger Builder

A small interactive Three.js language game for kids.

## Path

This game lives at:

`/burger-fr-lv/`

## Features

- French to Latvian vocabulary toggle
- Clickable menu cards
- Clickable 3D burger layers
- Learn mode and quiz mode
- Browser speech synthesis
- Hand-drawn paper style inspired by the reference drawing

## Notes

- The page loads Three.js from a CDN, so internet access is required.
- For a dedicated subdomain like `x.kartupelis.tv`, point DNS for that subdomain to GitHub Pages and either:
  - keep this repo as the Pages source and redirect the subdomain to `/burger-fr-lv/`, or
  - create a dedicated Pages repo/subdomain target for this game.
