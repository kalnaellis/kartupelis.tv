Kartupelis.TV

Official website and content hub for Kartupelis.TV a satirical transmedia universe centered on a talking potato banker turned social-media star and presidential candidate.
This repository contains the web platform for showcasing episodes, characters, updates, and future expansions of the Potato Man IP.

About

Kartupelis.TV mixes political satire, absurd character comedy, and Latvian-flavored cultural mischief into short-form content and a growing narrative world.

The site acts as:

a public-facing home for the brand

a release and archive portal for short clips

a launchpad for future extensions (merch, campaigns, interactive experiences, etc.)
