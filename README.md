Kartupelis.TV

Official website and content hub for Kartupelis.TV a satirical transmedia universe centered on a talking potato banker turned social-media star.
This repository contains the web platform for showcasing episodes, characters, updates, and future expansions of the Potato Man IP.

The site acts as:
a public-facing home for the brand
a release and archive portal for short clips
a launchpad for future extensions (merch, campaigns, interactive experiences, etc.)

Features
Landing page with brand identity
Episodes / Shorts listing
Character / Universe pages
News / Updates
Press / Contact
Fast, lightweight, mobile-first layout
